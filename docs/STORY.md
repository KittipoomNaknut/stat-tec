## แนวคิด

ผู้เล่นคือ **CEO คนใหม่** ของ **ดาต้าคาเฟ่** มี **[AI_NAME]** เป็นผู้ช่วย
ทั้งรอบเป็นเรื่องเดียว: **ราคากาแฟ** — ราคาเดียว → ราคาตามกลุ่มลูกค้า → ราคาตามเวลา
ตัวเลขต่อกันข้ามบท: ราคาจาก EP I เป็นราคาตั้งต้นของ EP II (บีบให้อยู่ในช่วง ฿59–120 ให้ยังมีเรื่องให้สู้) · กำไรทุกบทรวมเป็นกำไรในรายงาน CEO

**น้ำเสียงของ AI:** สุภาพ ฉลาด มีอารมณ์ขันนิดๆ เรียกผู้เล่นว่า "ท่าน CEO" ลงท้าย "ครับ"
**กติกา:** ≤ 12 คำ/บรรทัด · ขึ้นจอทีละ 1–2 บรรทัด · ทุกบทข้ามได้ด้วยการชี้ค้างที่ปุ่ม "ข้าม"
**เพดานเวลา:** ทุกช่วงมีเวลาสูงสุด — เกินแล้วไปต่อเอง · 1 รอบ **≤ 5 นาที**

**เส้นทางหลัก:** Attract → Welcome → **EP I** → **EP II** → **EP III** → **รายงาน CEO**

## EP III. ศึก 11.11 — ฟันป้ายราคา — _Dynamic Pricing_ (60 วิ)

**ท่า:** ปัดมือเร็ว ๆ (`slap`) · **เล่น:** 20 วิ · **เฉลย:** ≤ 25 วิ · ป้ายเรืองสีตาม demand curve จาก EP I (ไม่ต้องอ่านตัวเลข)

| Beat     | ข้อความ                                                                              |
| -------- | ------------------------------------------------------------------------------------ |
| Mission  | "วัน **11.11** มาแล้ว! ลูกค้าแห่เข้าร้าน"                                            |
|          | "ทุกวินาทีต้องเลือกราคาใหม่ ป้ายจะลอยมาเรื่อย ๆ"                                     |
| Tutorial | "ปัดมือผ่านป้าย **สีทอง** = ขายราคานี้"                                              |
|          | "ป้ายเทา = ขาดทุน · ป้ายแดง = แพงจนไม่มีใครซื้อ"                                     |
| Play     | _(ป้ายราคาพุ่งขึ้นจากเครื่องชงกาแฟ เร็วขึ้นเรื่อย ๆ · ฟันแล้วแตกเป็นเหรียญ · คอมโบ)_ |
| hint     | "เร็วอีก!" · "ระวังป้ายเทานะครับ!" · "ลูกค้าเยอะขึ้น ราคาดีก็เปลี่ยน!"               |
| Reveal   | "ท่านฟันได้ **{hits}** ป้าย · กำไร **฿{profit}**"                                    |
|          | "ทีนี้… ให้ AI ขายทั้งวันบ้างครับ"                                                   |
|          | _(กราฟ 24 ชั่วโมง: แท่งลูกค้า + เส้นราคา AI ขึ้นช่วงคนเยอะ ลงช่วงเงียบ)_             |
|          | "AI ปรับราคาทุกชั่วโมง ตามจำนวนลูกค้า"                                               |
|          | "AI กำไร **฿{aiProfit}** · ราคาเดียวได้ ฿{flatProfit}" → "มากกว่าเดิม **{gain}%**"   |
| Lesson   | "นี่คือ **Dynamic Pricing**"                                                         |
|          | "แอปเรียกรถ สายการบิน โรงแรม ใช้แบบนี้ทุกนาที"                                       |

> หมายเหตุ: สีป้ายคำนวณจาก demand curve เดียวกับ EP I × จำนวนลูกค้าตอนที่ป้ายลอยขึ้น — ช่วงคนเยอะ ราคาที่ดีที่สุดเลื่อนขึ้น ป้ายทองจึงเป็นราคาที่สูงขึ้น
