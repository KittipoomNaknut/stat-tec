# 015 — Cursor สั่น: กรองที่ตัว cursor + วาดลื่นที่ 60 fps

- **วันที่:** 2026-10-29 · **สถานะ:** สรุปแล้ว (รอลองสด)
- **เกี่ยวข้อง:** `app/src/gestures/cursor-smoother.ts` · `config/gestures.ts` (`smoothing`) · `app/src/hud/cursor.ts` · `tests/replay/cursor-smoothness.test.ts`

## คำถาม

เจ้าของงานลองแล้ว: "เคอเซอร์แม่นยำ ใช้ได้เลย แต่ว่ามันสั่น ไม่นิ่ง ไม่ smooth"

## ข้อมูลที่ใช้

session playground ที่อัดไว้ 2 ชุด (RTMPose, คนเดียว, 57 s และ 91 s) — **ไม่ได้เปิดกล้อง**; replay ผ่าน pipeline จริงทั้งหมด (PlayerLock → stabilizer → One Euro ของข้อต่อ → body space → CursorTracker)

## สาเหตุที่สงสัย

1. ความกว้างไหล่ (ตัวหาร) แกว่ง → วัดได้ **0.4–0.8%** เท่านั้น → ไม่ใช่ตัวการหลัก
2. **การขยาย:** พื้นที่มือข้างตัวกว้าง 1.3 SW ≈ 290 px ของกล้อง แต่ map ไปเต็มจอ 1920 px → ข้อมือแกว่ง 1 px ในกล้อง = cursor แกว่ง **~6.7 px** → ต้องกรองที่ cursor อีกชั้น
3. pose มา 30 Hz แต่จอวาด 60 Hz → cursor กระโดดเป็นขั้น

## การทดลอง

### รอบที่ 1 — ตัววัดผิด

วัด "สั่นตอนนิ่ง" เป็นระยะห่างจากค่าเฉลี่ยของ cursor **ดิบ** → ตัวกรองยิ่งแรงยิ่งดูแย่ (17 → 27 px) เพราะนับความหน่วงเป็นความสั่น → ทิ้ง

### รอบที่ 2 — ความสั่นเทียบกับตัวเอง (ค่าเฉลี่ย 300 ms รอบตัว)

ทุกค่าที่ลองลดได้แค่ 7.3 → ~5 px — ที่เหลือคือการโยกช้า ๆ ของแขนจริง ไม่ใช่สิ่งที่ตาเห็นว่า "สั่น"

### รอบที่ 3 — ตัววัดที่ตรงกับตา: **สั่น/เฟรม** = second difference (กระตุกกลับไปกลับมาระหว่างเฟรม) ตอนมือแทบนิ่ง

2D One Euro (cutoff ขึ้นกับ*ขนาด*ความเร็ว ไม่ใช่แยกแกน) + soft deadband — session side zone:

| ค่า                            | สั่น/เฟรม       | หน่วงตอนเลื่อนเร็ว (> 800 px/s) | กดติด  |
| ------------------------------ | --------------- | ------------------------------- | ------ |
| เดิม                           | 6.04 px         | 18 px                           | 23     |
| mc 0.5, β 2                    | 2.08            | 68                              | 23     |
| mc 0.5, β 8                    | 2.50            | 35                              | 23     |
| mc 0.5, β 16                   | 2.86            | 26                              | 23     |
| **mc 0.8, β 8, deadband 0.4%** | **2.17 (−64%)** | **39**                          | **23** |
| mc 0.8, β 4, deadband 0.8%     | 1.99            | 59                              | 23     |

session แรก: 5.57 → 2.51 px, กดติด 9 = 9 · ข้อแลก: ตอนสะบัดเร็วตามหลัง +~20 px (~20 ms) — ตอนเลื่อนช้า/ค้างแทบไม่รู้สึก

### รอบที่ 4 — การวาด (วัดไม่ได้ใน replay ดูด้วยตาตอนลองสด)

- **ลื่นระหว่างเฟรม pose:** HUD cursor ไล่ตามตำแหน่งล่าสุดแบบ exponential (τ 28 ms) ทุกเฟรมจอ → ไม่กระโดดเป็นขั้น 30 Hz; โผล่ขึ้นมาใหม่ = วางตรงมือทันที (ไม่ไถลมาจากที่เก่า)
- **ดูดเข้ากลางปุ่มระหว่างค้าง:** วาดเอียงเข้ากลางปุ่มสูงสุด 35% ตามความคืบหน้า — **ภาพเท่านั้น** การกดยังใช้ตำแหน่งจริง (ไม่เปลี่ยนความยาก)

## ข้อสรุป

- `CursorSmoother` (2D One Euro mc 0.8 / β 8 + deadband 0.4% ของจอ) อยู่ใน GestureEngine หลัง CursorTracker
- test กันถอย: replay ทั้ง 2 session → สั่น/เฟรมต้องลด > 50% และกดติดไม่ลดลง
- E2E 4/4 ผ่าน (ผู้เล่นสังเคราะห์ผ่าน smoother ด้วย)

## ต้องทดสอบต่อ

- ลองสดด้วยร่างกาย (`?playground` หรือหน้าหลัก + F2 ปิดเมาส์): รู้สึกนิ่งพอไหม / หน่วงจนรำคาญไหม — ถ้าหน่วง เพิ่ม β, ถ้ายังสั่น เพิ่ม deadband
