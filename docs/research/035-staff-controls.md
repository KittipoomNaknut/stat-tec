## ทางเดินของคำสั่ง

```
จอสตาฟ ─{command}─▶ server (/operator) ─▶ หน้าเกม (worker)
                                             ├─ pick → tracker.pick() → PlayerLock
                                             └─ อื่น ๆ → main → Experience.command()
หน้าเกม (worker) ─{lock: state, x, y} 5 ครั้ง/วิ─▶ server ─▶ จอสตาฟ (ไฮไลต์ PLAYER)
```

- **server ตรวจก่อนส่งต่อ:**
  - รับเฉพาะชื่อคำสั่งที่รู้จัก และพิกัด `pick` ต้องอยู่ในช่วง 0–1
  - คำสั่งมาได้เฉพาะจากจอสตาฟ (`/operator`) ซึ่งเปิดจากหน้าในเครื่องนี้ (origin localhost)
- **log:** ทุกคำสั่งเขียนลง booth log เป็น "🛠 สตาฟสั่ง: …"
  - เกมเขียนคำสั่ง start, skip, next, pause, reset
  - server เขียนคำสั่ง pick เพราะ pick ไปถึงตัวติดตามโดยตรง

## คำสั่ง

| ปุ่ม | คำสั่ง | ทำอะไร |
| --- | --- | --- |
| S | start | หน้าแรก → เริ่มรอบทันที (ไม่ต้องรอคนเดินเข้า) · ตอนต้อนรับ → ข้ามท่าชูสองมือ |
| N | skip | ข้ามบทพูด (เหมือนปุ่ม "ข้าม" ในเกม) |
| B | next | จบบทนี้ทันที ให้คะแนนตามผลที่ทำได้ถึงตอนนั้น แล้วไปบทถัดไป |
| P | pause | เรื่องและฉากหยุดนิ่ง (เวลาของท่าที่ถามอยู่ก็หยุดด้วย) กดอีกครั้งเพื่อเล่นต่อ |
| R | reset | กลับหน้าแรก (เหมือน F5) |
| คลิกที่คน | pick | ล็อกคนนั้นเป็นผู้เล่นทันที แม้ยืนนอกโซน |

**รายละเอียด pick:**
- **ถ้าเกมกำลังเล่นอยู่:** ใช้ player id เดิม เกมเล่นต่อกับคนใหม่โดยไม่เริ่มรอบใหม่
- **ถ้ายังไม่มีใครเล่น:** เริ่มรอบใหม่
- **หาคนจากจุดที่คลิก:** เลือกกรอบตัวที่จุดคลิกอยู่ข้างใน ถ้าไม่มี เลือกลำตัวที่ใกล้ที่สุดในระยะ 0.2 ของความกว้างภาพ
- **ถ้าไม่มีใครเลย:** คำสั่งรอ 1 วิ แล้วทิ้ง
- **เลือกได้เฉพาะคนที่ผ่าน body check:** เพราะเกมไม่เห็นคนที่ถูกตัด
- **ถ้าจำเป็นต้องเลือกคนที่ถูกตัด:** ปิดกฎด้วย `--no-body-check`

## หน้าจอแบบดิบ

- **พื้นดำ ตัวอักษร monospace:** ไม่โหลดฟอนต์จากเว็บ ไม่มี animation วาดใหม่ไม่เกิน 12 ครั้ง/วิ
- **บนภาพ:** ทุกโครงกระดูกมีป้าย `p0 PLAYER` / `p1 PASS (click = pick)` / `p2 ✕ HEAD หัวไม่อยู่ระหว่างไหล่` พร้อมคะแนนหัวกับไหล่ และค่า x
  - **กรอบที่ถูกตัด:** `d0 ZONE นอกโซน h=0.93`
  - **PLAYER (สีชมพู):** คือคนที่เกมกำลังตามอยู่ เทียบจากตำแหน่งที่เกมส่งมา
- **ด้านข้าง:**
  - `CAM / POSE / GAME / GPU / CPU / POWER / SEEN / LOCK` เป็นตัวเลขดิบ ขึ้นกรอบแดงเมื่อเกมไม่ได้เชื่อมต่อ, กล้องต่ำกว่า 20 fps หรือจับท่าเกิน 40 ms
  - ปัญหาที่ยังเปิดอยู่พร้อมวิธีแก้ และสรุปของวัน (`TODAY ...`)
  - ปุ่มคำสั่ง และบรรทัดยืนยัน `> 15:17:24 sent skip (! game not connected)`
  - log สด
