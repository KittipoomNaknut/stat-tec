# 010 — ทำไมปุ่มบางครั้งไม่ติด

- **วันที่:** 2026-10-28 · **สถานะ:** กำลังทำ
- **เกี่ยวข้อง:** ต่อจาก [009](009-cursor-rtmpose-calibration.md)

## คำถาม / สมมติฐาน
เจ้าของงานลอง `?playground` กับ RTMPose: "โอเค แต่บางครั้งปุ่มไม่ติด"
สาเหตุที่เป็นไปได้ (ยังไม่รู้ว่าข้อไหน):
1. cursor **ขยับหลุดปุ่ม**ระหว่างค้าง 1.2 s (เกิน grace 150 ms)
2. cursor **หายชั่วขณะ** (กฎแขนตรง / ความสูง / visibility ตัด)
3. เจ้าของงาน**รอไม่ถึง 1.2 s** แล้วเปลี่ยนใจ

## วิธีวัด
- playground บันทึกทุก "ความพยายามกด" (dwell เริ่ม → สำเร็จ / ไม่สำเร็จพร้อมสาเหตุและ progress ที่ไปถึง) + อัดท่า raw ไปพร้อมกัน
- เล่น 1–2 นาที → วิเคราะห์อัตราสำเร็จและสาเหตุ → ปรับ → **replay ท่าเดิม**พิสูจน์ว่าดีขึ้น

## เครื่องมือ (PR นี้)
- `debug/dwell-log.ts` — ทุก dwell ที่เริ่มขึ้น จบเป็น: **selected** / **left-target** (cursor ยังแสดงแต่ออกนอกปุ่ม + ระยะที่ออกไป) / **cursor-hidden** (cursor หายตอนหลุด) / **passed-by** (ไปไม่ถึง 25% — แค่เลื่อนผ่าน ไม่นับเป็นความล้มเหลว; 25% เป็นค่าที่ตั้งเอง ข้อมูลอาจบอกให้ปรับ)
- playground แสดงสรุปสด และ **F9** ดาวน์โหลด `*.attempts.json` (ปุ่ม, viewport, ผลทุกครั้ง) + `*.pose.json.gz` (ท่าทั้ง session) สำหรับ replay
- ทดสอบ: unit test ป้อน cursor ผ่าน `DwellDetector` ตัวจริง 5 กรณี; F9 ทดสอบใน Chrome ด้วยกล้องสังเคราะห์ (กล้องจริงไม่ถูกเปิด) — ได้ 2 ไฟล์ครบ

## ทางเลือกที่พักไว้
แยก "กำ / ชี้นิ้ว" ด้วยจุดมือ — เจ้าของงานให้ทำท้ายโปรเจค (ROADMAP); ปลายนิ้วของ RTMW สั่น 28 px ที่ 2 m / 720p ([006](006-pose-model-spike.md))
