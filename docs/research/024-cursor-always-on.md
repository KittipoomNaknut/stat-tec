# 024 — Cursor ติดมือตลอด + กรอบกล้องให้เห็นตัวเอง

- **วันที่:** 2026-11-02 · **สถานะ:** สรุปแล้ว (วัดกับ session ที่อัดไว้ · ยังไม่ได้ลองสดหลังแก้)
- **เกี่ยวข้อง:** `app/src/gestures/cursor.ts` · `config/gestures.ts` · `gestures/{dwell,slap,draw}.ts` (`liveCursor`) · `hud/cursor.ts` · `hud/player-cam.ts` · `main.ts` · `perception-server/.../__main__.py` (`--preview-fps`)

## โจทย์ (เจ้าของงาน)

"อยากให้เห็นตัวเองด้วยตอน detect" · "เคอเซอร์ เอาให้ติดมือแบบเสถียรสุด ๆ ไปเลย ติดตลอดก็ได้ แต่แม่น และ follow"

## สิ่งที่เปลี่ยน

1. **Cursor แสดงตลอดเวลาที่จับตัวผู้เล่นได้** และแยกเป็น 2 สถานะ:
   - _active_ (กดได้): ใช้กฎชี้แบบเดิม คือแขนตรงและยกเหนือเอว (research 009/010)
   - _inert_ (จาง กดไม่ได้): เมื่อไม่ได้ชี้ cursor จะตามมือข้างที่สูงกว่า และสลับข้างเมื่ออีกมือสูงกว่า ≥ 0.35 SW ต่อเนื่อง 200 ms
   - ถ้ามองไม่เห็นข้อมือชั่วครู่ cursor จะค้างที่เดิม ไม่หายไป
2. **dwell, slap และ draw ใช้ `liveCursor()`**: cursor ที่ inert นับเหมือนไม่มี ทั้งใน engine, replay test และ mouse
3. **ตัวกรองจูนให้ตามมือทันขึ้น** (ดูตาราง)
4. **กรอบกล้อง (player-cam) แทนโครงกระดูกเล็กเดิม**: ภาพจาก preview ของ service แสดงแบบกระจก มีโครงกระดูกทับ อยู่มุมขวาบนสุดของจอ (ตัวเลขกำไรขยับไปทางซ้ายของกรอบ) · preview เริ่มต้นที่ 24 fps (เดิม 10) · ภาพไม่ถูกบันทึก (ARCHITECTURE §17)

## รอบที่ 1: "active = มือเหนือเอว" ✗

ทดสอบด้วย replay แล้วพลาดหลายจุด: ตอนผู้เล่นขยับตัวเล่น ๆ (idle-fidget) ปุ่มเต็มจอถูกกด, slap ยิงเองใน walk-in-out กับ point-right-sweep, และปากกาลงตอนยืนเฉย ๆ เพราะท่าแตะหน้าหรือเกาหัวก็ทำให้มือสูงกว่าเอวเหมือนกัน → กลับไปใช้กฎชี้เดิมเป็นเงื่อนไขของ _active_ ส่วนการแสดง cursor ยังเปิดตลอด

## รอบที่ 2: ตัวกรอง (session playground 2 ชุด: sidezone / rtmpose)

| ชุดค่า                                | shake px  | lag px    | off px    | steady px | sel    |
| ------------------------------------- | --------- | --------- | --------- | --------- | ------ |
| ค่าเดิม (0.8/8 + gain 0.3 gap 60)     | 1.14/1.07 | 41/46     | 37/33     | 9.5/14.1  | 23/10  |
| smoothing อย่างเดียว                  | 2.10/2.18 | 36/39     | 19/18     | 13.6/22.0 | 23/9   |
| Holt (ทำนายทิศ) .15/.7                | 3.58/3.30 | 18/21     | 15/16     | 14.7/26.1 | 22/7 ✗ |
| **0.5/15 + gain 0.45 gap 35 (เลือก)** | 1.53/1.74 | **30/33** | **28/25** | 10.5/17.6 | 23/10  |

- **Visible** (สัดส่วนเวลาที่เห็น cursor ขณะจับตัวได้): 75/57% → **95/75%** · ที่เหลือคือช่วงก่อนเห็นข้อมือครั้งแรก
- กดติดเท่าเดิม, จังหวะกดต่างไม่เกิน 4 ms, ยังไปถึงขอบจอได้ 100%
- เงื่อนไขของ test precision ปรับเป็น steady ดีขึ้น ≥ 20% (เดิม ≥ 25%) และ off < 30 px (เดิม < 45 px)

## Preview กับ fps

ตอนแรกวัดได้ pose 30 → 17 fps หลังเปิด preview · วัดซ้ำสลับเปิด/ปิด 4 รอบได้ 16.8 fps ทุกรอบ และการเข้ารหัส JPEG ใช้แค่ 0.9 ms → **preview ไม่ใช่สาเหตุ** สาเหตุคือห้องมืดตอนกลางคืน กล้องจึงเปิดรับแสงนานขึ้นจนเฟรมลดลง
