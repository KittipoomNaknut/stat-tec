# 002 — ตัวกรอง One Euro

- **วันที่:** 2026-10-28 · **สถานะ:** สรุปแล้ว
- **เกี่ยวข้อง:** PR #8, #9 · `app/src/perception/one-euro.ts` · `app/src/config/perception.ts`

## คำถาม / สมมติฐาน
skeleton สั่นเพราะวาดค่าดิบจากโมเดลทุกเฟรม (ยังไม่มี filter เลย) — โมเดลที่หนักกว่าจะไม่แก้เรื่องนี้
สมมติฐาน: One Euro filter (กรองหนักตอนนิ่ง, กรองเบาตอนขยับเร็ว) ลดการสั่นได้มากโดยไม่หน่วง

## ข้อมูลที่ใช้
เหมือน [001](001-mediapipe-model-benchmark.md) — วัด jitter = ค่าเฉลี่ยการขยับระหว่างเฟรมของจมูก ไหล่ ข้อมือ ตอนยืนนิ่ง

## การทดลอง
### รอบที่ 1 — ออกแบบ
- กรองแยกแกน x, y, z ต่อ landmark; allocation-free
- **หารความเร็วด้วยความกว้างไหล่** → `beta` มีหน่วยเป็น SW/s ใช้ได้เท่ากันทุกระยะยืน (ค่า beta แบบ pixel จาก paper ใช้ไม่ได้เพราะหน่วยต่างกัน)
- ค่าเริ่มต้น `minCutoff 0.8 Hz, beta 3, dCutoff 1`
- unit test ครั้งแรกล้ม: "noise" ที่สร้างด้วย `sin(i·12.9898)` จริง ๆ เป็นคลื่น ~2 Hz เรียบ ๆ → เปลี่ยนเป็น sin-hash noise แล้วผ่าน (ปัญหาอยู่ที่ test ไม่ใช่ filter)

### รอบที่ 2 — วัดจริง

|---|---|---|---|
| lite | 5.78 px | 0.77 px | 87% |
| full | 5.34 px | 0.71 px | 87% |
| heavy | 4.56 px | 0.58 px | 87% |

## ข้อสรุป
ใช้ One Euro กับผู้เล่น; reset เมื่อผู้เล่นเปลี่ยนหรือหายเกิน 500 ms

- วัดแค่ตอนนิ่ง — **ความหน่วงตอนขยับเร็วยังไม่ได้วัดเป็นตัวเลข**
- ค่า filter จูนกับ MediaPipe และใช้ต่อกับ RTMPose โดยไม่ได้จูนใหม่ (spike [006](006-pose-model-spike.md) ใช้ค่าเดียวกันและได้ผลดี)
