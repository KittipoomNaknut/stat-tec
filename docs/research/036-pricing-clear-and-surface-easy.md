## เปลี่ยน

### 1. EP I ไม่มี quiz

- **ตัดออก:** quiz "ขายแก้วละ ฿200 จะมีคนซื้อไหม?" (ชูมือขวาหรือไขว้แขน) ตัดทั้งคำถาม คำเฉลย และตัวแปร `quizRight`
- **Mission:** "เปิดร้าน **ดาต้าคาเฟ่** วันแรก! ท่านตั้งราคากาแฟ"
- **Tutorial:** "เลื่อนมือ **ขึ้น** = ขึ้นราคา · เลื่อน **ลง** = ลดราคา" และข้อความใต้ราคาในกล่องใช้คำเดียวกัน
- **ท่าในรอบ:** เหลือ 2 ท่า คือชูสองมือตอนเริ่ม และกางแขนเป็นตัว T ใน EP II
  - E2E ปรับตาม: นับท่าที่ทำได้ 1 ครั้ง (ไม่รวมท่าเริ่มเกม) และลำดับเหตุการณ์ใน log ไม่มี `pose:right-up`

### 2. ตัวเลขราคาไม่ล้นกรอบ

- **สาเหตุ:** ตัวเลขใช้ขนาด 15vh เมื่อราคามี 3 หลัก (฿120) จึงกว้างกว่ากล่อง 27vw และชนแถบวัดระดับมือ
- **แก้:** ขนาดเป็น `min(13vh, 5.6vw)` และให้ตัวเลขทุกหลักกว้างเท่ากัน ไม่ให้ตัดขึ้นบรรทัดใหม่ แถบวัดไม่ถูกบีบ และเว้นระยะ 2vh
- **ตรวจด้วยภาพหน้าจอ:** ฿120 และ ฿30 อยู่ในกรอบทั้งคู่

### 3. กราฟ 3 มิติ

**เล่นง่ายขึ้น (มือเดียวทำได้ทั้งหมด):**

|                       | เดิม                | ใหม่                                                 |
| --------------------- | ------------------- | ---------------------------------------------------- |
| หมุน (เลื่อนซ้าย-ขวา) | ±0.95 rad (±54°)    | **±1.75 rad (±100°)**                                |
| ซูม                   | ต้องยกสองมือแล้วกาง | **มือเดียว ยกขึ้น = ซูมเข้า** (สองมือกางก็ยังซูมได้) |
| ช่วงซูม               | 0.8–1.45 เท่า       | **0.75–1.9 เท่า**                                    |
| เอียง                 | ตามความสูงของมือ    | คงที่ (ไม่ให้ซูมกับเอียงตีกัน)                       |
| ความไวตอบสนอง         | 220 ms              | 160 ms                                               |

- **ป้ายคำแนะนำ:** "✋↔ เลื่อนซ้าย-ขวา = หมุน · ✋↕ ยกขึ้น = ซูมเข้า"
- **บทพูด:** "กราฟ 3 มิติ! เลื่อนมือหมุน ยกมือซูม"
- **ลองซูมสุด 2.1 เท่าแล้ว:** กราฟบังหัวข้อ จึงใช้ 1.9

**รายละเอียดมากขึ้น:**

- ราคาทุก ฿20 (เดิมมี 3 ค่า) · ชั่วโมงทุก 2 ชั่วโมง (เดิมมี 3 ค่า) · ชื่อแกน "ราคาต่อแก้ว →", "ชั่วโมง ↗", "กำไร / ชม. ↑"
- **แกนกำไร:** มีขีดและตัวเลข 3 ระดับ (฿11,867 / ฿23,734 / ฿35,601)
- **ราคาของ AI บนสันสีทอง:** ทุก 2 ชั่วโมง เช่น ฿55 … ฿85
- **จุดสูงสุดของวัน:** มีเส้นทิ้งลงพื้นและป้าย "สูงสุด 20:00 · ฿124 · กำไร ฿35,600/ชม."
- **เส้นราคาเดียว:** มีป้าย "ราคาเดียวทั้งวัน ฿69"
