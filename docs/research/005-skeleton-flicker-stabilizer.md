# 005 — เส้น skeleton กะพริบ

- **วันที่:** 2026-10-28 · **สถานะ:** สรุปแล้ว
- **เกี่ยวข้อง:** PR #22 · `app/src/perception/stabilizer.ts` · `app/src/config/tracking.ts`

## คำถาม / สมมติฐาน
เจ้าของงาน: "เส้นตัวเส้นแขน ติดบ้างไม่ติดบ้าง ความแม่นยำต่ำ"
สมมติฐาน: overlay วาดเส้นเมื่อ visibility ≥ 0.5 แบบเปิด/ปิดตายตัว → ค่าที่แกว่งรอบ 0.5 ทำให้เส้นกะพริบ ทั้งที่ตำแหน่งถูก

## ข้อมูลที่ใช้
session MediaPipe — นับจำนวนครั้ง show↔hide ต่อ landmark ต่อคลิป

## การทดลอง
### รอบที่ 0 — วัดก่อนแก้
| จุด | ซ่อน | ติด↔ดับ/คลิป |
|---|---|---|
| มือ/ศอกข้างที่ชี้ | 0% | 0 |
| ข้อมือข้างที่ห้อย | 58–93% | 27–76 |
| ศอกข้างที่ห้อย | 30–35% | 34–62 |
| สะโพก | 15–33% | 30–54 |
→ สมมติฐานถูก + ส่วนหนึ่งเป็นเพราะมุมกล้อง (ข้างที่ห้อย/สะโพกอยู่ขอบล่างของภาพ)

### รอบที่ 1 — stabilizer
- visibility smoothing (τ 120 ms) เขียนกลับลง channel
- hysteresis: แสดง ≥ 0.6, ซ่อน < 0.3
- ระหว่างโมเดลไม่แน่ใจ (raw < 0.5) ใช้ตำแหน่งที่มั่นใจล่าสุดได้ ≤ 200 ms แทนค่าที่เดา
- overlay: จางตาม visibility + glow

**ผล:** ติด↔ดับต่อคลิป 27–76 → **0–6** · ส่วนที่มองไม่เห็นจริง (ข้อมือซ้าย 88% ใน point-hold) ซ่อนนิ่งแทนกะพริบ

## ข้อสรุป
ใส่ stabilizer ก่อน One Euro ใน PoseTracker; replay test คุม ≤ 6 ครั้ง/คลิป

## ข้อจำกัด / ต้องทดสอบต่อ
แก้การแสดงผล ไม่ได้แก้ความแม่นของโมเดล → นำไปสู่ [006](006-pose-model-spike.md)
