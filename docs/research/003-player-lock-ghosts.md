# 003 — PlayerLock กับ "ผี" ของ MediaPipe

- **วันที่:** 2026-10-28 · **สถานะ:** สรุปแล้ว
- **เกี่ยวข้อง:** PR #7 (พบครั้งแรก), #16, #19 · `app/src/perception/player-lock.ts` · `app/src/perception/landmarks.ts` · fixture `2026-10-28-adult1-2m-indoor.pose.json.gz`

## คำถาม / สมมติฐาน
ทดสอบ overlay ครั้งแรก: นั่งใกล้กล้อง คนเดียวถูกนับเป็น 2 pose (เส้นฟ้า + ทองซ้อนกัน)
ต้องการ: ล็อกผู้เล่น 1 คน, คนอื่นแย่งไม่ได้, ไม่นับคนเดียวเป็นสองคน

## การทดลอง
### รอบที่ 1 — ตัดสินซ้ำด้วยระยะ torso (PR #16)
ซ้ำ = torso ห่างกัน < 0.6 SW → unit test จับได้ว่า **คนตัวใหญ่ (ใกล้กล้อง) ที่เดินมาบังผู้เล่น ถูกมองเป็นซ้ำ แล้วผู้เล่นตัวจริงถูกตัดทิ้ง**
→ เพิ่มเงื่อนไข: ขนาดต้องใกล้กัน (< 1.4×)

### รอบที่ 2 — replay จาก session จริงชุดแรก (PR #19)
พบ 5 ปัญหาที่ test สังเคราะห์จับไม่ได้:

| พบ | ตัวเลข | แก้ |
|---|---|---|
| หันข้างแล้วไหล่ซ้อน → พิกัด body space พุ่ง | ข้อมือ 22 SW (ปกติ ±3) | `bodyScalePx` = max(ไหล่, 0.65 × ความยาวลำตัว) — 0.65 วัดจาก session (0.18/0.28 ≈ 0.64) |
| ผี = fit เพี้ยนของคนเดิม | box ซ้อนกัน 91–100% แต่ไหล่หด 0.02–0.05 → กฎ "ขนาดใกล้กัน" จากรอบ 1 พลาด | ซ้ำ = box containment ≥ 85%, **เก็บตัวที่ box ใหญ่กว่า** (ผีมี confidence สูงกว่าด้วยซ้ำ) |
| ล็อกไหลไปตามผี (raise-both) | ผี scale 0.083 vs จริง 0.16 → ตัวจริงหลุดเกณฑ์ → ผู้เล่นใหม่ #2 | scale อ้างอิงแบบ EMA (0.1/เฟรม) + จับคู่ต้องต่างไม่เกิน 1.7× |
| ผีโผล่เดี่ยว ๆ (draw, swipe) | ถูกนับเป็น "คนอื่น" | ผีของผู้เล่น = torso อยู่ในกรอบผู้เล่น (+1 SW) และเล็กกว่า 1/1.7 → ไม่ใช่คนอื่น, ไม่ใช้เป็นตำแหน่ง, แต่นับว่าผู้เล่นยังอยู่ |
| candidate นับตัวเองเป็นคนอื่น | – | แก้ |

### รอบที่ 3 — swipe ยังเหลือ 1 เฟรม
ท่าปัดเร็ว กรอบจากเฟรมก่อนเลื่อนไม่ทัน → เผื่อขอบกรอบ 1 SW → replay ผ่านครบ

## ทางเลือกที่ไม่เลือก
ใช้ confidence ตัดสินว่าตัวไหนจริง — ข้อมูลแสดงว่าผีมักมี confidence **สูงกว่า**

## ข้อสรุป
ล็อก < 0.7 s, ID คงที่ทุกท่า, ไม่รายงาน "คนอื่น" ใน session ที่อยู่คนเดียว (replay test คุมไว้)

## ข้อจำกัด / ต้องทดสอบต่อ
- ยังไม่มี session ที่มีคนอื่นเข้ามาจริง — เคส "คนเดินแทรก" ยืนยันแค่ด้วย unit test สังเคราะห์
