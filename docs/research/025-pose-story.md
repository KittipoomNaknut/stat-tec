## โจทย์ (เจ้าของงาน)

"แก้ story ใหม่ให้น้องได้ใช้ pose เยอะ ๆ เนื้อหาเยอะไปไม่น่าสนใจ"

## สิ่งที่ทำ

- **ตัวจับท่านิ่ง** (body space): ชูสองมือ, ชูมือซ้าย, ชูมือขวา, กางแขนเป็นตัว T, ไขว้แขน
  - ท่าต้องเห็นต่อเนื่อง 150 ms ก่อนจะนับ แล้วค้างอีก 700 ms ถึงจะเลือก
  - ใช้ได้เฉพาะตอนที่ฉากถามด้วยท่า (`PosePrompt`) ช่วงอื่นไม่มีผลอะไร
- **การ์ดท่า (`PosePrompt` / `askPose`)**: การ์ดเป็นรูปคนก้านไม้ทำท่านั้น และเติมสีขึ้นระหว่างที่ผู้เล่นค้างท่า
  - ทุกคำถามมีเวลาจำกัดตามเวลาในเรื่อง (หยุดเกมแล้วเวลาก็หยุด)
  - มี 2 แบบ: กลางจอ หรือเป็นรายการในกรอบด้านข้าง
- **ท่าที่ใช้ในเรื่อง:**
  - Welcome: ชูสองมือ (แทนการชี้ค้างที่ปุ่ม)
  - EP I: คำถาม "฿200 จะมีคนซื้อไหม" (ตอบได้ 2 ท่า)
  - EP II: เลือกทางสู้ด้วย 3 ท่า (แทนการชี้ปุ่ม 3 ปุ่ม)
  - EP III: กางแขนเป็นตัว T ก่อนเฉลยผลของ AI
- **บทพูด:** ทั้งเรื่องเหลือ 33 บรรทัดจาก 52 · เวลาทั้งรอบ ≈ 3.8 → **≈ 3.2 นาที** (welcome 12 · I 64 · II 29 · III 48 · รายงาน 39 วิ)

## ตรวจกับ session ที่อัดไว้

| คลิป (RTMPose)                               | ผล                                                                 |
| -------------------------------------------- | ------------------------------------------------------------------ |
| raise-both                                   | both-up ✓ (2 ครั้งจาก 2 รอบที่ชู)                                  |
| raise-right                                  | right-up ✓                                                         |
| walk-in-out · idle-stand · point-hold · slap | ไม่มีท่าไหนถูกเลือก ✓                                              |
| idle-fidget                                  | cross (เจ้าของงานไขว้แขนจริงในคลิปนั้น)                            |
| sweep · draw · swipe · free-play             | ชี้สูงเลยหัวถูกอ่านเป็น "มือขึ้น" → จึงให้ท่ามีผลเฉพาะตอนที่ฉากถาม |

MediaPipe (ตัวสำรอง) อ่านท่าชูสองมือเป็นตัว T เพราะเป็นภาพหลอนที่บันทึกไว้แล้วใน README ของ fixture · ตู้จริงใช้ RTMPose
