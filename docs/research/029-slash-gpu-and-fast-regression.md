## 1. กระตุกตอนฟันป้าย

**อาการจาก booth log (2 รอบ):** ระหว่างเล่นฟันป้ายเกิดปัญหา 2 อย่างพร้อมกัน
- `low-fps`: กล้องได้ 9.1 fps
- `slow-pose`: จับท่าช้า 98–110 ms

ทั้งสองอย่างนาน 21–25 วิ ซึ่งเท่ากับช่วงเล่นพอดี แล้วหายเองเมื่อจบช่วงเล่น

**สมมติฐาน:** ภาพของฉากแย่ง GPU กับตัวจับท่า เพราะทั้งคู่ใช้ RTX 4060 ตัวเดียวกัน

**วิธีวัด (ไม่ใช้กล้อง):**
- รันตัวจับท่าจริง (YOLOX-tiny + RTMPose-x TensorRT) กับภาพนิ่ง 1280×720 ที่ 30 รอบ/วิ และจด ms ทุกวินาที
- ระหว่างนั้นเปิดฉากฟันป้ายใน Chromium แบบเห็นหน้าจอ (ใช้ GPU) ด้วย `slash.spec`
- **ตัวที่สงสัย:** ฉบับก่อนใส่ canvas `shadowBlur` ให้ป้ายทุกใบทุกเฟรม และวาดซ้ำ 2 ครั้งตอนป้ายถูกฟันขาด

| รอบ | ภาพป้าย | ตอนว่าง | ระหว่างฟันป้าย | GPU |
| --- | --- | --- | --- | --- |
| 1 | เดิม (`shadowBlur`) | 18 ms · 30/วิ | **81–92 ms · 11–13/วิ** | 100% |
| 2 | ปิดเงา (ทดสอบ) | 18.6 ms | 22 ms · 30/วิ | 70% |
| A/B เดิม | เดิม | 29 ms (Firefox ใช้ GPU อยู่) | 79–95 ms · 11–13/วิ | |
| A/B ใหม่ | **เงาเป็นภาพสำเร็จ** | 17.8 ms | **20–23 ms · 30/วิ ตลอด** | |

- **ยืนยันสมมติฐาน:** อาการเหมือนใน booth log ทั้งตัวเลขและระยะเวลา
- **แก้:** วาดกรอบป้ายพร้อมเงาเรือง**ครั้งเดียว**ต่อสีและขนาดจอ เก็บเป็นภาพ แล้วทุกเฟรมใช้ `drawImage` แปะภาพนั้นแทน
  - หน้าตาเหมือนเดิม เทียบภาพหน้าจอแล้ว
  - คำนวณงานเรืองแสงครั้งเดียว ไม่ต้องทำซ้ำทุกเฟรม

**ระวังหน้างาน:** Firefox ที่เปิดค้างไว้ใช้ GPU 50–70% (วัดด้วย `nvidia-smi pmon`) ทำให้ตัวจับท่าช้าลงจาก 18 เป็น 29 ms แม้ไม่ได้เล่นอะไร
- วันงาน**ต้องปิดโปรแกรมอื่นทั้งหมด** (เพิ่มในคู่มือสตาฟแล้ว)

## 2. เฉลย Regression เร็วขึ้น

- **ข้อมูลขึ้นกราฟ:** เดิมทีละวัน มีป้ายตัวเลข X/Y และเส้นนำ ใช้ประมาณ 7.6 วิ
  - ตอนนี้ทั้ง 13 จุด**ลอยออกจากแถวในตาราง**ไปตกที่ (ราคา, แก้ว) **พร้อมกัน** ห่างกันจุดละ 40 ms ใช้ประมาณ 1.8 วิ
  - ลองแบบให้ป้ายตัวเลขบินพร้อมกันแล้ว ป้าย 26 อันทับกันจนอ่านไม่ออก จึงไม่ใช้
- **AI ลากเส้น:** แต่ละครั้งที่ลอง 650 + 250 → 380 + 100 ms
- **เส้นรายได้:** 1.4 → 0.8 วิ
- **แกนและตาราง:** สั้นลงประมาณครึ่งหนึ่ง
- **ลบ:** CSS ป้ายตัวเลขกับเส้นนำที่ไม่ใช้แล้ว
