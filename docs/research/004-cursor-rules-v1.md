# 004 — เกณฑ์ cursor รอบแรก (MediaPipe)

- **วันที่:** 2026-10-28 · **สถานะ:** สรุปแล้ว (ปรับต่อใน [009](009-cursor-rtmpose-calibration.md))
- **เกี่ยวข้อง:** PR #21 · `app/src/gestures/cursor.ts` · `app/src/config/gestures.ts`

## คำถาม / สมมติฐาน
"เมื่อไหร่นับว่ากำลังชี้" — ถ้าใช้แค่ "มือยกสูง" ท่าเกาหัวจะติด cursor
สมมติฐาน: ตอนชี้แขนเหยียด, ตอนเกาหัวแขนพับ

## ข้อมูลที่ใช้
session MediaPipe (fixture `…-indoor`) — วัด wrist–shoulder extension และความสูงเหนือสะโพก ต่อคลิป

## การทดลอง
### รอบที่ 0 — ดูข้อมูลก่อนตั้งกฎ
| | extension (5–95%) |
|---|---|
| ชี้ (sweep/hold) | 0.90–1.72 SW |
| เกาหัว/จับหน้า | 0.26–0.71 SW |
reach ตอน sweep: x −1.4…1.7, y −1.1…0.9 SW → ใช้เป็นกรอบแปลงเป็นจอ

### รอบที่ 1 — เริ่มเมื่อ สูง ≥ 0.5 + เหยียด ≥ 0.9
- เกาหัว: cursor กะพริบ **2 เฟรม** (66 ms) → ปุ่มไม่ถูกกด แต่เห็นจุดวาบ
- ชี้มือซ้าย: มือขวาที่ห้อยต่ำมาแย่ง cursor — **71%** ของเฟรมเป็นมือซ้าย

### รอบที่ 2 — ต้องชี้ต่อเนื่อง 100 ms + สูง ≥ 0.8 (ปล่อย 0.6)
เกาหัว 0 เฟรม ✅ — แต่ชี้มือซ้ายเหลือ cursor **55%**
ไล่สาเหตุทีละเฟรม: 61 เฟรมเป็นตอนชี้ขอบล่าง (มือต่ำกว่า 0.8)

### รอบที่ 3 — ปล่อยที่ 0.3 (เริ่มยาก–ค้างง่าย)
ยังได้ 55% → ดู timeline: 2.5 s แรกเจ้าของงานยังไม่เริ่มชี้ (reaction time), และช่วง 4.4–5.1 s **ชี้ขึ้นไปทางกล้อง แขนดูสั้น 0.7**
→ test นับตั้งแต่เริ่มชี้จริง + ปล่อย extension ที่ 0.6 → ผ่าน (> 85%)

## ข้อสรุป
| | เริ่ม | ค้าง |
|---|---|---|
| สูงเหนือสะโพก | 0.8 SW | 0.3 SW |
| เหยียด | 0.9 SW | 0.6 SW |
| ต่อเนื่อง | 100 ms | – |
dwell 1.2 s, หลุดได้ ≤ 150 ms, cooldown 800 ms
