# คู่มือสตาฟบูธ STAT WARS (1 หน้า)

> สำหรับคนเฝ้าบูธที่ไม่ใช่โปรแกรมเมอร์ · ทุกคำสั่งพิมพ์ใน Terminal ที่โฟลเดอร์ `STAT_TEC`

## ก่อนเปิดบูธ (10 นาที)

- [ ] **เสียบสายชาร์จ** โน้ตบุ๊ก (ใช้แบตแล้วเกมจะกระตุก)
- [ ] **กล้อง:** ตั้งกลางจอ หันหาจุดยืน · ติดเทปจุดยืนห่างกล้อง **ประมาณ 2 เมตร** ให้กล้องเห็นตั้งแต่หัวถึงสะโพก
- [ ] **แสง:** เปิดไฟให้สว่าง ไม่มีหน้าต่างหรือไฟจ้าอยู่ข้างหลังผู้เล่น
- [ ] **ป้าย privacy:** "กล้องใช้จับท่าทางเท่านั้น ไม่มีการบันทึกภาพ"
- [ ] **ตั้งค่าจอ:** TV เปิด Game Mode และปิด motion smoothing
- [ ] **ปิดโปรแกรมอื่นทั้งหมด** โดยเฉพาะเว็บเบราว์เซอร์อื่น เพราะใช้ GPU ร่วมกับตัวจับท่า และทำให้เกมกระตุก

## เปิด

```bash
./scripts/demo.sh start     # เกมเปิดเต็มจอเอง
./scripts/demo.sh log       # เปิดอีกหน้าต่าง: ดูสถานะสด
```

- **เช็กหน้า log:** บรรทัดบนสุดต้องเป็น**สีเขียว** และกล้องต้องได้ประมาณ **30 fps**
- **ลองเล่นเอง 1 รอบ:** เมื่อเริ่ม ให้ชูสองมือ 🙌 แล้วเล่นจนจบ
- **ช่องดูตัวเองมุมขวาบน:** ถ้าไม่เห็นตัวเองในช่องนี้ แปลว่ากล้องไม่เห็นผู้เล่น

## ระหว่างวัน

| เห็นอะไร                                   | ทำอะไร                                                                                                     |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| กล่องแดงในหน้า log                         | ทำตามบรรทัด **→** ที่เขียนใต้ปัญหา (เช่น เช็กสาย USB กล้อง, เปิดไฟ, เสียบชาร์จ) · กล่องจะหายเองเมื่อแก้ได้ |
| เกมค้างกลางรอบ / มีคนเดินออกไปแล้วเกมยังรอ | กด **F5** (กลับหน้าแรก ไม่ต้องปิดเกม)                                                                      |
| cursor เป็นสีจาง ๆ กดไม่ได้                | บอกผู้เล่นให้ **กางแขนออกข้างตัวแล้วชี้** (ไม่ใช่ชี้ตรงเข้าหาจอ)                                           |
| ผู้เล่นตัวเล็ก ระบบจับไม่ได้               | ให้ยืนเข้าใกล้ขึ้นนิด ให้เห็นทั้งตัวในช่องมุมขวาบน                                                         |
| มีหลายคนยืนในภาพ                           | ให้คนเล่นยืนตรงกลาง คนอื่นยืนหลังเส้นหรือออกด้านข้าง                                                       |
| "ตัวจับท่าไม่ได้ทำงาน" ในหน้า log          | ปิด Chrome (Alt+F4) แล้วพิมพ์ `./scripts/demo.sh start` ใหม่                                               |
| เครื่องร้อนมาก (GPU/CPU แดงในหน้า log)     | ยกเครื่องให้อากาศถ่าย เปิดพัดลม พักเครื่องระหว่างรอบได้                                                    |

## ปิด (ท้ายวัน)

- **ปิด Chrome** (Alt+F4): ทุกอย่างปิดตามเอง
- **ถ้ายังมีอะไรค้าง:** พิมพ์ `./scripts/demo.sh stop` ใช้ `./scripts/demo.sh status` เช็กได้ว่าหยุดหมดแล้ว
- **log ของวันนี้:** อยู่ที่ `~/.cache/stat-tec/logs/events-วันที่.jsonl` เก็บแค่ตัวเลขและเหตุการณ์ ไม่มีภาพ ส่งไฟล์นี้ให้ทีมพัฒนาไว้จูนเกมได้

## เรื่องความเป็นส่วนตัว (ถ้ามีคนถาม)

- **ไม่บันทึกภาพหรือใบหน้า:** ภาพจากกล้องใช้จับท่าในเครื่องแล้วทิ้งทันที ไม่ออกจากเครื่อง
- **ไม่ใช้ชื่อจริง:** อันดับในตารางใช้ชื่อเล่นสุ่ม เช่น "สิงโตหัวไว #86"
